# Dynamic labelling — wording review

Development trial 1.19. Covers every example in the current collection. The public app remains on 1.18.

Direct entry keeps its general questions. Example-led entry carries the wording below into the calculator, result and Explore. The four outcome values, probability, starting resources and calculation rules are unchanged.

A and C always refer to the first scenario; B and D to the second. The probability slider always measures the first scenario. Simplified mode uses one answer for the alternative; Normal exposes both.

Money is a net change: costs use a minus sign. Happiness uses the existing numerical scale, with context-specific descriptive endpoints. These are wording changes rather than new numerical weights.

## 1. Should I spend more on advertising?

**Go:** run the campaign  
**Alternative:** keep my current marketing plan

| Outcome | Slider question |
|---|---|
| A | If I run the campaign and customers respond strongly… |
| B | If I run the campaign and customer demand disappoints… |
| C | If I keep my current marketing plan and customers respond strongly… |
| D | If I keep my current marketing plan and customer demand disappoints… |

**Simplified alternative:** If I keep my current marketing plan…

**Probability question:** How likely is a strong customer response?
It measures: customers respond strongly. The other scenario is: customer demand disappoints.
Example probability: 50% (not a new forecast).

**Resources question:** How much money does my business have before this campaign?

**Outcome-slider endpoints:** Down [amount] ↔ Up [amount]. Exact boxes say “Net change (− for costs)”.

**Green result:** Run the campaign.  
**Red result:** Keep the current plan.
