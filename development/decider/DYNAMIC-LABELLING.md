# Dynamic labelling — wording review

Development trial 1.19. Every current example is covered. The public app remains on 1.18.

A/C share the first scenario, B/D the second. Probability always refers to the first scenario. Direct entry retains its general wording. Calculation inputs and numerical scales are unchanged.

## 1. Should I spend more on advertising?

Go: run the campaign. Alternative: keep my current marketing plan.

| Outcome | Question |
|---|---|
| A | If I run the campaign and customers respond strongly… |
| B | If I run the campaign and customer demand disappoints… |
| C | If I keep the current plan, though the campaign would have drawn a strong response… |
| D | If I keep the current plan and the campaign would have drawn a weak response… |

Simplified alternative: If I keep my current marketing plan…

Probability: How likely is a strong customer response if I run the campaign?
First scenario (50% in the example): customers respond strongly. Other scenario: customer demand disappoints.

Resources: How much money does my business have before this campaign?

Money endpoints: Down [amount] ↔ Up [amount]. Exact boxes use net change, with negative amounts for costs.

Green result: Run the campaign. Red result: Keep the current plan.
