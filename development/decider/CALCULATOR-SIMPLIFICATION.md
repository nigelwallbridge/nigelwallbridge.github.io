Example Entry has a fixed authored title, short period, back link, compact complementary probabilities and optional Money resource help. Alternative heading and mode control are retained. Historical serious-harm flags have no active effect; the original veto engine is archived outside the build. Utility formula, precision module, all example values and resource-exhaustion rules are retained. Public /sigfi/ is outside this release.
